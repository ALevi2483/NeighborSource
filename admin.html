Administration

NeighborSource administrative functions are managed separately from the public website.

ADMIN ACCESS

Public admin controls are disabled

NeighborSource is currently hosted as a public static website. For security, administrative records and moderation controls are not exposed through this page.

This is intentional. Provider submissions, recommendations, service requests, reports, listing updates, and other administrative records should continue to be reviewed through the private NeighborSource management system.
ADMIN WORKFLOW

What is currently reviewed

Public submissions are separated from approved public directory information.

🧰

Provider Listings

Review new businesses and individual service providers before they appear publicly.
👍

Recommendations

Review community recommendations before connecting them to provider profiles.
🔎

Service Requests

Review requests submitted by people looking for local help.
➕

Provider Suggestions

Review providers suggested by community members for possible inclusion in the directory.
✏️

Listing Updates

Review requests to correct, update, add, or remove provider information.
⚑

Reports

Review reports involving inaccurate, misleading, duplicate, or concerning listings.
✉️

Contact Messages

Review questions, feedback, technical issues, and other messages submitted through the website.
✓

Verification

Manage applicable phone, business, license, and insurance verification information.
SECURITY

Administrative information stays off the public site

This page intentionally does not contain passwords, private email addresses, moderation notes, submission records, Google Sheet links, approval controls, or other administrative information.

A future web-based admin dashboard should only be added after secure authentication and authorization are in place.

Important: Hiding an admin page or using a secret URL is not security. Any future administrative dashboard must require actual authentication before private information or moderation actions are exposed.
